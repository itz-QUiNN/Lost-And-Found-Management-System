# 🧭 Lost and Found Management System

Welcome to a clean and friendly Lost & Found project built in **C++**. This system helps track found items, match them with owner claims, and print the results in a clear, easy-to-read way.

---

## ✨ What’s inside

- `lost_and_found.cpp` – Main C++ program that processes lost and found records.
- `lost_items.csv` – Example list of found items waiting to be claimed.
- `claims.csv` – Example list of user claims for lost items.

---

## 🎯 Project purpose

This project demonstrates a simple lost-and-found workflow with:

- **CSV file reading and parsing**
- **Record matching** between found items and claims
- **Formatted output** for clear results
- **Basic data handling** in C++

---

## 🚀 How to use

1. Open this folder in your C++ editor.
2. Compile `lost_and_found.cpp` with your C++ compiler.
3. Run the executable.
4. The program loads data from `lost_items.csv` and `claims.csv` and shows which items are matched or still unclaimed.

---

## 📁 File details

- `lost_items.csv`
  - Stores found item details such as name, location, and date.

- `claims.csv`
  - Stores owner claims, including claimant name, item description, and claim details.
